# 初期構成

## 目的

携帯とPCのどちらからでも現在地が分かり、PC停止中の調査・監視と、PC上の再現可能な実装を分離して運用する。

## 役割

- Google Drive `AI-Workspace`: 資料、メモ、依頼、成果物への入口となる正本。携帯・PCで共通利用する。
- ChatGPT Work Cloud: PC停止中も必要な調査・監視を実行する。結果は操作盤から追える形にする。
- Codexローカル環境: コード、設定、テスト、再現手順を作る。
- GitHub: ローカル実装の履歴と遠隔バックアップを置く。リポジトリ作成前なので接続先は未設定。

## Google Drive構成

```text
AI-Workspace/
├── 00_Inbox/       携帯・PCから入れる未整理の依頼と資料
├── 10_Projects/    稼働中プロジェクトの資料
├── 80_System/      運用ルールと System Brief
└── 90_Archive/     終了済み資料
```

## 情報の流れ

1. 新しい依頼や資料を `00_Inbox` に入れる。
2. 継続案件だけ `10_Projects` に移し、プロジェクトごとの正本を決める。
3. コードとテストはローカルで実行し、GitHubで履歴管理する。
4. PC停止中の継続処理はChatGPT Work Cloudに限定し、ローカルPC依存の処理を持たせない。
5. 完了した資料を `90_Archive` に移す。

## 採用しない構成

Obsidianは現時点の中心にはしない。Markdown編集には強いが、Google Driveと併用するとメモの正本が二つになり、携帯・PC間の共有経路が増えるため。必要になった時点で、Google Driveを置き換えるのではなくローカル閲覧層として再検討する。
